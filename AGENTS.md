# Repository instructions

- For every requested compiler change, update its current development version,
  completed work, next target, and remaining release gates in Hylang-Docs when the change affects them.
  Use the [Hydrogen — Development project](https://github.com/orgs/Aurora-softwares/projects/4)
  for current progress. A Git tag is historical release evidence, not the source of the
  current development version.
- When editing a checklist, use 🟢, 🟡, and 🔴 traffic lights instead of checkbox syntax.
